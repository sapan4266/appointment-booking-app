Appointment Booking App

This is a simple full-stack appointment booking application built as a mini project.

The application allows users to book patient appointments and manage them from one place. Appointment data is stored in MongoDB, so the data remains available even after refreshing the page.

Features
Book a new appointment
Enter patient name and mobile number
Select doctor, date, and time
View all booked appointments
Mark an appointment as Completed
Cancel an appointment
Delete an appointment
Basic form validation
Success and error messages
Data stored permanently in MongoDB
Responsive user interface
